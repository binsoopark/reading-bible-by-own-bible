내 성경 읽기 개인정보처리방침

시행일: 2026년 6월 7일

내 성경 읽기(영문명: Reading My Bible)는 사용자가 보유한 성경 데이터 파일을 Android 기기에서 읽고 검색할 수 있도록 돕는 성경 리더 앱입니다. 본 개인정보처리방침은 앱이 어떤 정보를 처리하는지 설명합니다.

1. 수집하는 개인정보

앱은 이름, 이메일 주소, 전화번호, 위치 정보, 결제 정보 등 사용자를 식별할 수 있는 개인정보를 수집하거나 개발자 서버로 전송하지 않습니다.

2. 기기 안에 저장되는 정보

앱 사용 중 다음 정보가 사용자의 기기 안에 저장될 수 있습니다. 이 정보는 앱 기능 제공을 위한 로컬 저장 정보이며, 개발자에게 전송되지 않습니다.

  • 선택한 성경 데이터 폴더 정보
  • 최근 읽은 성경 역본, 책, 장 정보
  • 북마크, 메모, 하이라이트, 읽음 표시
  • 글자 크기, 줄 간격, 팔레트 등 읽기 설정
  • 성경 데이터 파일의 읽기 성능 개선을 위한 로컬 캐시

3. 성경 데이터 파일

앱은 사용자가 직접 선택한 bdf, lfa 등 성경 데이터 파일을 읽습니다. 앱은 사용자의 성경 데이터 파일 내용을 개발자 서버로 업로드하지 않습니다.

4. 선택형 데이터 다운로드

사용자가 설정 화면에서 성경 데이터 다운로드 기능을 선택하면, 앱은 GitHub Release에 게시된 bible.zip 파일을 내려받을 수 있습니다. 이 과정에서 앱은 파일 다운로드를 위해 인터넷에 연결하지만, 사용자의 개인정보를 개발자 서버로 전송하지 않습니다. 다만 GitHub 또는 네트워크 제공자는 일반적인 서버 로그를 처리할 수 있습니다.

5. 공유 및 클립보드

사용자가 직접 선택한 성경 구절을 복사하거나 다른 앱으로 공유할 수 있습니다. 이 동작은 사용자가 명시적으로 실행한 경우에만 이루어지며, 공유 이후의 데이터 처리는 선택한 외부 앱의 정책을 따릅니다.

6. 제3자 제공 및 판매

앱은 사용자의 개인정보를 수집하지 않으며, 개인정보를 제3자에게 판매하거나 제공하지 않습니다.

7. 보안

앱은 사용자의 성경 파일과 기록을 기기 안에 저장합니다. 기기 자체의 보안, 백업, 파일 접근 권한 관리는 Android 운영체제와 사용자의 기기 설정에 따릅니다.

8. 아동의 개인정보

앱은 아동을 대상으로 개인정보를 수집하지 않습니다. 앱은 계정 생성, 광고, 사용자 추적 기능을 제공하지 않습니다.

9. 개인정보처리방침 변경

앱 기능 또는 관련 법령 변경에 따라 본 개인정보처리방침이 수정될 수 있습니다. 변경 시 이 페이지의 시행일을 갱신합니다.
